🔊 Tốc độ phát âm:

🅰️ Nhóm AAA — Không đổi gì

V1 = V2 = V3. Chỉ cần học 1 lần dùng mãi!

  • Thường là động từ ngắn, kết thúc bằng -t hoặc -d
  • Mẹo: "cut cắt, hit đánh, put đặt — ba thì giống hệt nhau!"
cut → cut → cut put → put → put hit → hit → hit let → let → let

🔵 Nhóm ABA — V1 = V3

V2 khác nhưng V1 và V3 giống nhau. Học V2 là xong!

  • Hay gặp dạng: -ame/-ome → -ame/-ome
  • Mẹo: "Quay về điểm xuất phát — come came come!"
come → came → come run → ran → run become → became → become

🔴 Nhóm ABC — Cả 3 đều khác

Phổ biến nhất, cần thuộc lòng cả 3 dạng!

  • Nhiều từ quan trọng nhất nằm ở nhóm này
  • Mẹo: "Đọc thành vần: sing-sang-sung, ring-rang-rung"
  • Mẹo: "i → a → u: begin-began-begun"
go → went → gone write → wrote → written sing → sang → sung

🟠 Nhóm ABB — V2 = V3

V2 và V3 giống nhau, chỉ cần nhớ V2 là dùng được cho cả V3!

  • Nhiều từ kết thúc bằng -ght
  • Mẹo: "bought-caught-taught — mua-bắt-dạy đều là -ought!"
buy → bought → bought teach → taught → taught think → thought → thought

🎵 Mẹo Vần Điệu (Rhyming)

Nhóm các từ có âm giống nhau để nhớ cùng lúc:

  • -ing/-ang/-ung: sing-sang-sung, ring-rang-rung, drink-drank-drunk
  • -ow/-ew/-own: know-knew-known, grow-grew-grown, blow-blew-blown
  • -ake/-ook/-aken: take-took-taken, shake-shook-shaken
  • -ive/-ave/-iven: give-gave-given, drive-drove-driven

🧠 Mẹo Câu Chuyện (Story)

Tạo câu chuyện để nhớ nhiều từ cùng lúc:

  • "Tôi went (go) đến chợ, bought (buy) táo, came (come) về nhà, ate (eat) ngon lắm!"
  • Mỗi buổi sáng: viết 5 từ V1→V2→V3 trước khi ăn sáng
  • Dán giấy note ở gương/tủ lạnh

🎲 Tuỳ chỉnh bài tập ngẫu nhiên

✏️ Bài 1 — Điền V2 (Quá khứ)

Nhìn V1 → điền V2 (dạng quá khứ đơn) vào ô trống

✏️ Bài 2 — Điền V3 (Phân từ quá khứ)

Nhìn V1 → điền V3 (past participle) vào ô trống

🎯 Bài 3 — Trắc nghiệm V2

Chọn V2 đúng của động từ được cho

🔥 Bài 4 — Điền đầy đủ V2 + V3

Cho V1 → điền cả V2 lẫn V3 vào 2 ô trống

🔍 Bài 5 — Tìm từ không cùng nhóm
